# Percetakan Canggih Naya

## Menjalankan
Buka folder ini melalui XAMPP/Apache, atau jalankan `php -S localhost:8000` dari folder proyek.
Kemudian buka `http://localhost:8000`.

## Bagian pengerjaan
- Level 1: `level1/etalase.php`
- Level 2: `level2/hitung.php`
- Level 3: `level3/simpan.php`, `level3/struk.php`, `level3/hapus.php`
- Level 4: `level4/baca.php`, `level4/simpan.php`

Jangan ubah `index.php`, `proses.php`, `ringkasan.php`, atau `hapus.php`.
